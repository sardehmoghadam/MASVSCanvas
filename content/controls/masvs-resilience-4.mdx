## What This Control Means

Detect debuggers, emulators, hooking frameworks (Frida/Xposed), and other runtime instrumentation to raise the cost of dynamic tampering.

## Why This Matters

Dynamic analysis enables live code modification and extraction; impeding it protects runtime behavior and data.

## Main Security Requirement

> The app implements anti-dynamic analysis techniques.

## Common Failure Patterns

- Ignoring debugger and emulator signals.
- Leaving obvious hooks for Frida or Xposed.
- No reaction when instrumentation is detected.

## Secure Implementation

Detect debuggers and known hooking frameworks with layered checks, verify environment consistency, and degrade or block when instrumentation is present.

## Key Rules

- Detect debuggers and emulators.
- Detect hooking frameworks.
- Respond to instrumentation (block or degrade).

## Checklist for Code Review

- Are debugger and emulator checks present?
- Are Frida/Xposed-style hooks detected?
- Is there a runtime response to detection?
