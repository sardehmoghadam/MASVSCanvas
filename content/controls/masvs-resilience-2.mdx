## What This Control Means

Detect modifications to the binary and resources (repackaging, patching) to prevent cheat builds and tampered re-distribution.

## Why This Matters

A locally modified app can bypass checks or be redistributed with backdoors.

## Main Security Requirement

> The app implements anti-tampering mechanisms.

## Common Failure Patterns

- Providing no signature or integrity verification.
- Verifying integrity client-side only with trivially bypassable checks.
- Ignoring tamper events at runtime.

## Secure Implementation

Verify the app signature at runtime and check critical code and resource integrity, with redundant checks in native code where relevant.

## Key Rules

- Verify the app signature at runtime.
- Check the integrity of code and resources.
- Apply multiple, layered checks.

## Checklist for Code Review

- Is the app signature verified?
- Are code and resources integrity-checked?
- Are checks layered and non-trivial to bypass?
