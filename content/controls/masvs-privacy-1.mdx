## What This Control Means

Request the minimum permissions and data needed, obtain informed consent, and ensure third-party SDKs honor consent rather than collecting by default.

## Why This Matters

Every unnecessary permission or SDK data grab expands the impact of a breach and erodes user trust.

## Main Security Requirement

> The app minimizes access to sensitive data and resources.

## Common Failure Patterns

- Requesting broad permissions up front without need.
- SDKs collecting before consent is given.
- Not auditing the SDK supply chain for data collection.

## Secure Implementation

Request permissions at the point of use, review SDKs for data collection, and gate SDK initialization behind consent.

## Key Rules

- Request only what the feature needs.
- Gate SDKs behind consent.
- Audit the SDK supply chain.

## Checklist for Code Review

- Are permission requests minimal and contextual?
- Do SDKs honor consent signals?
- Is the SDK data flow documented?
