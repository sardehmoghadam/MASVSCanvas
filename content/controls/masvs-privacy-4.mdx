## What This Control Means

Provide mechanisms to manage, modify, and delete user data and to revoke consent or adjust privacy settings.

## Why This Matters

User control is a core privacy principle and a legal requirement in many jurisdictions.

## Main Security Requirement

> The app offers user control over their data.

## Common Failure Patterns

- No way to delete or export user data.
- Consent that cannot be revoked.
- Not re-prompting when more data than stated is requested.

## Secure Implementation

Expose data management/export/delete options, honor consent revocation, and re-prompt when expanding the data scope.

## Key Rules

- Provide export and deletion options.
- Allow consent revocation.
- Re-prompt when the data scope grows.

## Checklist for Code Review

- Can users view/export/delete their data?
- Is consent revocation honored?
- Does the app re-request consent on scope changes?
