## What This Control Means

Increase the cost of reverse-engineering by obfuscating control flow, strings, and data so static analysis is slow and confusing.

## Why This Matters

Understanding the app is the first step to tampering; raising that cost protects intellectual property and deters casual attackers.

## Main Security Requirement

> The app implements anti-static analysis mechanisms.

## Common Failure Patterns

- Shipping unobfuscated builds with symbols and plain secrets.
- Relying on obfuscation alone for security.
- Breaking functionality or stability with aggressive transforms.

## Secure Implementation

Enable compiler optimizations and symbol stripping, apply a maintained obfuscator (e.g. R8/ProGuard plus native obfuscation), and move critical logic server-side where possible.

## Key Rules

- Strip symbols and enable optimizations.
- Obfuscate control flow and strings.
- Keep critical logic server-side where possible.

## Checklist for Code Review

- Are symbols stripped and optimizations enabled?
- Is string and control-flow obfuscation applied?
- Is confidential logic kept server-side?
